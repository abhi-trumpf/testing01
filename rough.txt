1. Array Syntax Error
Error: int a = [1,2,3,9,10];
Fix: In C#, you must use curly braces {} to initialize an array, and you must include the square brackets [] after the variable type.

int[] a = {1, 2, 3, 9, 10};
Case Sensitivity: C# is very strict. It must be .ToArray(), not .toarray().
